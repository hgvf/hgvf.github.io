# 你有紀律嗎? — 內建策略說明

共 15 個內建策略，分成趨勢跟隨、動能突破、均值回歸三類。網站上只放白話規則、旋鈕和題庫回測；文獻出處整理在這份文件的第 6 節。

## 0. 頁面

**開始頁**：策略依類型分三排，點一個就在下面顯示它的白話規則（買、賣、加碼、部位）。「每筆最多賠（1R）」可選帳戶的 0.5% / 1% / 2% / 3% 或「照策略」：
- 依風險決定股數的策略（`risk_percent`、`max_loss_amount`）直接改成這個風險。
- 其他策略（固定比例、波動度）保留原本算法，再加上 `sizing.caps.maxRiskPct` 上限（`engine/plugins.js` 的 `applyRiskLimit`）。

**遊戲頁**：右側「策略」卡列出白話規則、圖上標記（買訊、賣訊、加訊、你的成交）和每條線的意思。線圖可以另外開均線（5/20/60）、布林（20, 2）、RSI(14)、KD(9,3,3)、MACD(12,26,9)，預設全關；RSI、KD、MACD 和策略自己的副圖指標共用一個副圖，一次只開一個。

**策略頁（`#/editor`）**

| 位置 | 內容 |
|---|---|
| 策略總覽 | 三種類型的比較，以及全部策略的題庫回測表（可篩選、排序） |
| JSON 寫法（`#/guide`） | 範例、每個欄位、條件式語法、指標 / 停損 / 部位的完整清單（由引擎的登錄表產生）、常見錯誤 |
| **規則** 分頁 | 白話規則，數字跟著旋鈕即時更新；用到的指標各做什麼 |
| **調整** 分頁 | 5–8 個旋鈕，說明在旁邊的「?」 |
| **進階編輯** 分頁 | 指標、策略變數、買進、部位、停損、停利、賣出條件、加碼、違規判定；附條件式小抄 |
| **回測** 分頁 | 完整題庫回測（與買進持有對照、分盤勢） |
| **JSON** 分頁 | 只顯示規則欄位，可以貼上別人分享的策略 |
| 右側 | 快速回測（42 題樣本，按下才下載約 1 MB）、背景區預覽 |

完整題庫的回測是預先算好的 `config/preset-stats.json`（約 15 KB），沒有新增外部套件。

## 1. 三大類型

| 類型 | 想法 | 典型勝率 | 主要風險 | 本站策略 |
|---|---|---|---|---|
| **趨勢跟隨** | 價格已經在走的方向會持續；不預測，只跟隨 | 25–40%，靠少數大賺撐起整體 | 盤整時被來回洗 | 200 日均線擇時、黃金交叉、20 日突破、海龜 55 日、ADX/DMI、SuperTrend |
| **動能突破** | 強勢股（創新高、波動收斂後放量）傾向繼續強 | 30–40% | 假突破 | Minervini 趨勢模板、52 週高點、TSMOM 12 個月動能、Clenow 迴歸動能、布林收斂突破 |
| **均值回歸** | 多頭結構中的短期超跌會反彈 | 55–75% | 偶爾的大虧（跌了不回來） | Connors RSI(2)、Connors Double 7、多頭回檔 EMA20、MACD 零軸下金叉 |

## 2. 進場、出場、艙位控管技術

### 進場
- **通道突破**：收盤突破前 N 日高點（Donchian / 海龜），代表創新高、趨勢啟動。
- **均線交叉 / 站上均線**：例如 50/200 黃金交叉、站上 200 日均線（Faber），反應慢、假訊號少。
- **趨勢強度確認**：ADX 向上穿越 20–25 且 +DI > −DI；SuperTrend 由空翻多。
- **趨勢模板 + 突破**：先確認長期均線多頭排列、接近 52 週高點，再等短期突破與量增（Minervini）。
- **超跌回檔**：長期趨勢向上（> 200 日均線）時，短期指標極端（RSI(2) < 10、收在 7 日最低、MACD 零軸下金叉）才買。
- **動能門檻**：過去 12 個月報酬轉正（TSMOM）、股價逼近 52 週高點（George & Hwang）。
- **波動收斂後突破**：布林寬度縮到近期最窄後的突破（Squeeze）。

### 出場（停損與停利可疊加，有效停損取最高、只上不下）
- **初始停損**：固定 ATR 倍數（2–3 ATR）、固定 %（7–8%，O'Neil / Minervini）、結構停損（前波低點下方）。
- **保本**：賺到 1–2R 後停損移到均價，最差打平。
- **移動停利**：Chandelier（進場後最高價 − 3 ATR）、ATR trailing、均線移動停損（跌破 EMA20 / 50 日線）、N 日低點（海龜 10 日低點）、SuperTrend 線。
- **訊號出場**：反向訊號，例如死亡交叉、−DI 反穿 +DI、站回 5 日均線（均值回歸的獲利了結）。
- **時間停損**：持有 N 根仍沒到目標就出場（RSI(2) 用 10 根）。
- **分批停利**：到 2–3R 先賣 1/3–1/2，剩下的讓移動停利處理。

### 艙位控管（部位大小）
- **固定比例風險**：股數 = 權益 × 1% ÷ 停損距離。每筆停損都只虧帳戶 1%（= 1R），是本站多數策略用的方法。
- **固定最大虧損金額**：股數 = 金額 ÷ 停損距離，概念同上，用固定點數。
- **波動度目標**：股數 = 權益 × 目標 % ÷ ATR。波動大的股票買少、波動小的買多（Clenow、TSMOM；Moreira & Muir 2017 發現這樣調整能提高多數因子的 Sharpe）。
- **帳戶 % 部位**：股數 = 權益 × % ÷ 價格。資產配置型策略用（Faber 擇時用 90%）。
- **上限**：單筆市值上限（maxPositionPct），以及含加碼的總未保護風險上限（maxOpenRiskR）。
- **金字塔加碼**：只在獲利中加碼（例如已賺 1R 且再漲 1 ATR），加碼量遞減或固定為初始的一半，加碼後停損移到均價，總風險不超過上限。虧損中加碼（攤平）會被判違規。


## 3. 策略變數與旋鈕（想新增或修改內建策略時）

**策略變數**：條件式裡的門檻寫成 `$名稱`，數值放在 `vars`。引擎在編譯條件式前會代入數值，所以門檻可以用旋鈕調整，不必改字串：

```json
"vars": { "rsiTh": 10 },
"entry": { "signal": "close > sma200 and rsi2 < $rsiTh" }
```

**旋鈕**：寫在 preset 的 `knobs`，每個旋鈕用 `path` 指到一個數值。

| path 寫法 | 指到 |
|---|---|
| `ind:<指標 id>.<參數>` | 指標參數，例 `ind:dc20.length` |
| `stop:<停損類型>.<參數>` | 第一條該類型停損的參數，例 `stop:atr_initial.k` |
| 點分路徑（陣列用索引） | 其他欄位，例 `vars.rsiTh`、`targets.0.at.r`、`sizing.caps.maxPositionPct` |

其他欄位：
- `min` / `max` / `step`：範圍與間距。
- `unit`：顯示單位。
- `pct: true`：以 % 顯示。
- `fmt: 'x'`：以倍數顯示。
- `help`：白話說明。

**白話規則**：寫在 preset 的 `plain: { buy: [], sell: [], add: [] }`。字串裡的 `{path}` 會換成目前的數值（path 寫法同旋鈕），所以調旋鈕時白話規則會跟著變：

| 寫法 | 顯示 |
|---|---|
| `{ind:dc20.length}` | 數值本身，例 20 |
| `{targets.0.fraction\|%}` | 乘 100 加 %，例 50% |
| `{vars.nearHigh\|below}` | (1 − 值) 的 %，例 0.75 → 25% |
| `{vars.aboveLow\|above}` | (值 − 1) 的 %，例 1.3 → 30% |

測試（`engine/test/presets.test.mjs`）會檢查：每個旋鈕都指到存在的數值、預設值在範圍內、調到最大值後策略仍有效、每個指標都有角色說明、白話規則裡的 `{path}` 都指得到數值。

**方法**（定義見 `engine/backtest.js`，網站的快速回測用同一份程式）
- 每個策略在題庫每一題的可操作區間跑「影子帳戶」，所有進出場與加碼都照規則自動執行。
- 每題獨立計算，起始權益相同，不計交易成本。
- Sharpe 的算法：把所有題目的日報酬合併起來算，空手的日子報酬算 0。
- 重跑方式：`node blind-chart/tools/backtest-presets.mjs --bank <題庫資料夾>`。

**怎麼讀這張表**
1. **單一股票、約一年的盲測裡，沒有一個規則策略的 Sharpe 贏過買進持有。** 原因有兩個：
   - 題庫的多頭、空頭、盤整各佔約 1/3，多頭題目平均年化 +73%。
   - 依單筆風險決定部位的策略，大部分時間只用一小部分資金。
2. **策略的價值在空頭與回撤控制。** 空頭題目裡，買進持有平均年化 −27%、最大回撤中位數約 45%；各策略只虧 0.1–8%。
3. **比較策略看 Sharpe**，它不受部位大小影響。報酬、回撤的絕對值主要反映的是部位大小。
4. **相對較好的幾個**：
   - 200 日均線擇時：Sharpe 最高，但回撤也最大。
   - Connors RSI(2)、Double 7：勝率約 63%，盤整也不虧。
   - TSMOM：PF 1.49，平均持有約 20 根。
   - Clenow：每筆期望值最高（+0.34R），但交易很少。
5. **海龜 55 日在單一股票上是負的**：原法則靠分散在幾十個期貨市場。
6. **偏誤提醒**：
   - 題庫的「策略池」題目，是因為原本三個策略（20 日突破、多頭回檔、海龜）至少有 3 次訊號才被選進來，這三個策略可能被高估。
   - 題庫只收現存股票（survivorship bias），買進持有也可能被高估。
   - 回測沒有交易成本。交易次數多的策略（RSI(2)、Double 7）扣成本後影響最大。

| 52 週高點 | George & Hwang (2004) *Journal of Finance* 59(5) | 1963–2001 美股，與傳統動能同量級（約每月 0.45%），預測力優於過去報酬、長期不反轉 |
| TSMOM | Moskowitz, Ooi & Pedersen (2012) *Journal of Financial Economics* 104(2) | 58 個期貨市場每一個的 12 個月動能都是正報酬；分散組合 Sharpe 第三方摘要約 1.0–1.3 |
| Clenow 迴歸動能 | Clenow (2015) *Stocks on the Move* | 第三方 1999–2014 回測：年化約 12%（S&P 500 約 5.2%），最大回撤約 −24%（S&P 500 約 −55%）；也有分析認為 R² 沒有預測力 |
| ADX / DMI | Wilder (1978) | 原書以範例說明，沒有現代標準的績效統計 |
| 布林收斂、SuperTrend、MACD | Bollinger (2001)、Carter (2005)、Appel (1979) | 實務常用，缺少同儕審查的績效研究 |
