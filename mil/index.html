MILITARY RESEARCH ZONE

Military軍事專區 · 情報 / 戰史 / 系統研究

以「實體研究（Research Entity）」為核心的互動式軍事情報站。整合武器系統 3D 探索、 戰史消耗分析、系統譜系、台海活動基線、文件敘事漂移與每日官方採購動態。所有重要資訊皆可追溯來源。

資料與真實性原則

  • · 能靜態就不進 Firestore：戰史 / 武器 / 文件 / 演習皆為版本控管的靜態 JSON，零配額成本。
  • · 只有每日變動、需 LLM 判讀者才用 DB：每日軍武動態（採購合約）與每日彙整。
  • · 來源優先序：一級官方（DoD / 各國國防部 / 原廠 / GAO）＞ 研究機構（CSIS / IISS / CRS）＞ 專業媒體。
  • · 合成 / 示意資料的頁面頂端皆有橘色警示條標明；每則新聞皆保留官方來源連結。
